# Practical 5 - 0/1 Knapsack Problem

## Summary
This practical demonstrates the 0/1 Knapsack Problem using dynamic programming.
It calculates the maximum value that can be selected without exceeding the given capacity.
The approach compares including and excluding each item to find the best possible profit.

## Conclusion
Thus, dynamic programming provides an efficient solution to the 0/1 Knapsack problem.
It avoids repeated work and ensures an optimal result for every capacity value.
This method is widely used in optimization and resource allocation problems.
