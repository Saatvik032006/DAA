Summary

This Python program uses Kruskal’s Algorithm to find the Minimum Spanning Tree (MST) of a weighted graph. It sorts the edges by weight and selects the smallest edges without creating cycles. The find() and union() functions help avoid cycles and connect the vertices. The total weight of the MST is 13.

Conclusion

Thus, Kruskal’s Algorithm successfully finds the Minimum Spanning Tree with minimum total cost by selecting the lowest-weight edges without forming cycles.
